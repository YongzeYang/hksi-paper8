# 02 公式手册：先写变量、时点、单位和条件

[首页](../README.md) · [数学预备课](../01-零基础预备课/04-复利折现与公式读法.md) · [案例数据](04-海港面包公司案例数据.md)

公式是机制的压缩表达，读不懂时回到讲义例子。金额默认同一货币；百分率代入通常用小数；期数与利率频率匹配；中间保留小数，最后舍入。以下默认没有未说明的中途资金流。

## 1 收益、权重与时间

| 用途 | 公式与变量 | 完整小例子与条件 |
|---|---|---|
| 持有期总收益 | R=(P₁−P₀+D)/P₀ | P₀10、P₁12、D0.4：2.4/10=24%，未计费 |
| 现金口径净回报 | R=(S+D−B)/B | 总支出10050、卖净10950、净息100：1000/10050≈9.95% |
| 连续多期收益 | R=∏(1+Rₜ)−1 | +20%、−20%：1.2×0.8−1=−4% |
| 回本所需涨幅 | L/(1−L) | 损失50%后需50%/50%=100%；L<100% |
| 单期组合回报 | Rₚ=ΣwᵢRᵢ | 80%赚10%、20%亏20%：8%−4%=4%；用期初价值权重 |
| 复合年化 | (1+R)^(1/t)−1 | 半年4%：1.04²−1=8.16%；t以年表示 |
| 实际回报 | (1+名义R)/(1+通胀)−1 | 5%、3%：1.05/1.03−1≈1.94% |
| 本币回报 | (1+外币资产R)(1+外币升值率)−1 | +10%、−5%：1.1×0.95−1=4.5%；统一报价方向 |
| 终值 | FV=PV(1+r)ⁿ | 1000、5%、2年：1000×1.05²=1102.50 |
| 单笔现值 | PV=FV/(1+r)ⁿ | 两年后1102.50、5%：除1.05²得1000 |
| 多笔现值 | PV=ΣCFₜ/(1+r)ᵗ | 年末各100、5%：100/1.05+100/1.05²≈185.94 |
| 名义转有效年率 | (1+j/m)ᵐ−1 | 名义6%、半年复利：1.03²−1=6.09%；不是有效年率再直接除 |

∏ 表示连乘，Σ 表示求和，w为权重，CF为指定时点现金流。不要把一年期利润与半年期回报直接比较。

## 2 指数与公司行动

| 用途 | 公式 | 演算与条件 |
|---|---|---|
| 股权市值 | 股价×股份数 | 12×1000万=1.2亿；不等于公司现金 |
| 简化市值指数 | 当前合资格市值/基期市值×基值 | 1.02亿/1亿×1000=1020；需按方法调整 |
| 价格加权 | Σ价格/除数 | 20和80、除数2：50；公司行动可能调整除数 |
| 拆股理论价 | 旧价/每旧股变新股数 | 一拆二：12/2=6；忽略其他变化 |
| 红股理论价 | mP/(m+n) | 四送一：4×12/5=9.60；不另缴款 |
| 理论除权价TERP | (mP+nS)/(m+n) | m旧股配n新股、认购价S；四供一：(48+8)/5=11.20 |
| 每旧股附权价值 | P−TERP | 12−11.20=0.80；一新股需四份时合计3.20 |
| 理论除息价 | P−每股分配 | 12−0.40=11.60；实际市价不保证如此 |

## 3 债务与融资

| 用途 | 公式 | 演算与条件 |
|---|---|---|
| 面值贴现报价价格 | P=F(1−dt/B) | F10万、d4%、90/360：99000；贴现率分母为面值 |
| 投入简单收益报价 | P=F/(1+yt/B) | 同数字：约99009.90；不要与上一式混用 |
| 贴现票据投入回报 | (F−P)/P | 1000/99000≈1.0101%，为90天而非年回报 |
| 普通债券价格 | P=ΣC/(1+y)ᵗ+F/(1+y)ⁿ | 每年C50、F1000、n2、y4%：1018.86；信用现金流按假设 |
| 当前收益率 | 年票息/P | 50/950≈5.263%；不含还本价差 |
| 一年期YTM | (本金+票息)/P−1 | 1050/980−1≈7.1429%；多期需解方程 |
| 全价 | 净价+应计利息 | 990+15=1005；应计依日数和条款 |
| 麦考利久期 | Σ[t×PV(CFₜ)]/P | 两年案例、4%：约1.9528年；以现金现值加权 |
| 修正久期，年付 | Dmac/(1+y) | 1.9528/1.04≈1.8777；其他付息频率须调整 |
| 小幅价格近似 | ΔP/P≈−Dmod×Δy | Dmod4、收益率+0.005：约−2%；忽略凸性 |
| 账户权益 | V−L | 资产9万、借款5万：权益4万；应计成本另扣 |
| 权益回报 | (期末权益−初始权益)/初始权益 | 初始5万、末4万：−20%；中途流入另处理 |
| 简化维持临界值 | V=L/(1−m) | 借5万、维持权益比例30%：约71428.57；仅题设规则 |
| 空头损益 | (卖价−买回价)×数量−成本 | 50卖、40买、100股：毛利1000；借券成本另扣 |

## 4 衍生工具

| 用途 | 公式 | 演算与条件 |
|---|---|---|
| 多头期货毛损益 | (平仓价−开仓价)×乘数×张数 | (20120−20000)×50×1=6000；空头反向 |
| 单期利率掉期净额 | (收息率−付息率)×名义本金×期间比例 | 收4.5%、付3%、1000万、1年：收15万 |
| 买认购到期净额 | max(Sₜ−K,0)−c | 120、100、6：14；按每单位，费用时间利息忽略 |
| 买认沽到期净额 | max(K−Sₜ,0)−p | 100、80、4：16；确认K与S方向 |
| 买Call打平 | K+c | 100+6=106；只适用所示到期净损益 |
| 买Put打平 | K−p | 100−4=96；提前卖出看期权价格 |
| 局部Delta敞口 | Delta×合约单位×有符号张数 | 0.6×100×(−2)=−120股；卖出张数为负 |
| Vega近似 | 单位Vega×波动率变化单位 | 每百分点0.10、升3个百分点：+0.30 |
| 权证到期收益 | 普通期权价差×每份对应股数 | 10份对应1股、价差20：每份2 |
| 名义／有效杠杆 | 对应标的价值/产品价；再乘Delta | 100×0.1/2=5；Delta0.6时约3；局部估计 |
| ETF溢价 | (市价−NAV)/NAV | 10.20相对10：2%；折价可用负值或明确幅度 |

max(x,0) 表示x为负就取0，是买方可以不行使的数学表达。合约总额要乘单位；普通卖方损益为对应买方相反数，保证金占用与现金流时点另算。

## 5 比率、估值与技术分析

| 用途 | 公式 | 案例D或独立例子 |
|---|---|---|
| 毛利／营业／净利率 | 对应利润/收入 | 20/50=40%；8/50=16%；5.6/50=11.2% |
| 平均余额 | (期初+期末)/2 | 权益(16+20)/2=18，仅近似全年平均 |
| ROE | 归属相关股东利润/平均相关权益 | 简化5.6/18≈31.11% |
| 本文ROA | 净利润/平均总资产 | 5.6/38≈14.74%；其他资料可有分子调整 |
| 流动／速动比率 | CA/CL；(CA−存货等)/CL | 20/10=2；(20−6)/10=1.4 |
| 本文负债权益比 | 总负债/权益 | 20/20=100%；只用计息债务是另一口径 |
| 利息保障 | EBIT/利息 | 8/1=8倍；不代表全部本金偿付能力 |
| 存货周转 | 销售成本/平均存货 | 30/5=6次；天数365/6≈60.83 |
| 应收周转 | 赊销收入/平均应收 | 50/7≈7.14次；天数7/50×365=51.1 |
| EPS | 归普通股盈利/加权普通股数 | 5.6百万/10百万=0.56元；优先股息需处理 |
| P/E；P/B | P/EPS；P/BVPS | 12/0.56≈21.43；12/2=6 |
| 股息率；派息比率 | DPS/P；DPS/EPS | 0.4/12≈3.33%；0.4/0.56≈71.43% |
| 戈登模型 | V=D₁/(r−g)，r>g | D₀0.4、g3%、r8%：D₁0.412，值8.24 |
| 简单移动平均 | 窗口价格之和/窗口数 | 10、11、12、11、13：57/5=11.4 |
| RSI | 100−100/(1+RS) | RS=平均上涨/平均下跌=2：66.67；平均法按定义 |
| 简化随机%K | (收−低)/(高−低)×100 | 收18、低10、高20：80；高=低需另处理 |

## 解题前五问

在算什么？用哪个时点？分母是什么？利率和期间同单位吗？费用、税和合同乘数有没有遗漏？每次写出这五个检查，会比再背十条没有条件的公式更有效。
