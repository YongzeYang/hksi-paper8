# 05 错题本与掌握清单

## 1 怎样记录才有用

先写自己当时怎样想，再写正确解释。只抄答案无法找出问题。错误可标记为概念、分母／单位、计算、条件、审题、制度版本六类；同一题可能有两类。

| 题号 | 原来的想法 | 错误原因 | 正确解释与补读 | 复习日期 |
|---|---|---|---|---|
| 示例：自编供股题 | 旧价与供价简单平均 | 忽略四比一股数权重 | 先列四旧股价值，加一股认购款，再除五；读公司行动 | 自行填写 |

下方自行继续增加记录，已懂的题也保留原错误，便于看到思路变化。第一次订正后，隔约3天、一周、两周再试；这只是学习建议，不要求固定日历。

## 2 掌握程度的三个层次

“见过”是看懂定义；“会做”是在不看答案时解释或计算；“会迁移”是换金额、换情境、增加一个条件仍能判断。只有第三层才能说明知识真正连接起来。

给每项写0、1、2：0尚需读讲义，1可独立完成基本题，2可解释条件并迁移。不要用阅读页数代替掌握程度。

- [ ] 计算含股息、含费用的持有期回报，并说明分母。
- [ ] 从逐年表解释复利，再从未来向今天折现。
- [ ] 用两个成分计算价格加权与市值加权回报。
- [ ] 用现金流与折现率两条线解释宏观冲击。
- [ ] 说明IPO中谁得到新股与旧股各部分款项。
- [ ] 区分保荐、承销、托管、登记与研究工作。
- [ ] 算拆股、红股、派息与供股的理论结果。
- [ ] 解释普通股与优先股的权利及剩余风险。
- [ ] 区分基金NAV和ETF交易价，算溢价。

- [ ] 比较短期工具，并识别贴现报价分母。
- [ ] 画债券现金流，算价格、当前收益率及简单YTM。

- [ ] 写出四种普通期权仓位的方向与义务。

- [ ] 解释Delta、Gamma、Theta、Vega和Rho的单位与局限。
- [ ] 比较保护性Put、备兑Call、价差和跨式。
- [ ] 解释牛熊证强制收回与代币化的附加风险。
- [ ] 区分提交、成交、结算和交收。
- [ ] 按营业日数T+2，逐项计算交易费用。
- [ ] 为客户资产设计授权、分工、对账和异常升级。
- [ ] 解释HKIDR、OTCR和USM各自解决的问题。
- [ ] 读三张表并计算比率，说明口径。
- [ ] 算股息折现和相对估值，列出假设与失效条件。
- [ ] 算均线、RSI或随机指标，并给出失败情境。
- [ ] 不查资料完成两套模拟，再解释自己的错题。
