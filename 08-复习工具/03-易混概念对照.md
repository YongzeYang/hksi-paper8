# 03 易混概念：用反例检查理解

[首页](../README.md) · [术语表](01-中英术语表.md) · [公式手册](02-公式手册.md)

| 容易混淆 | 区别 | 用一个问题自测 |
|---|---|---|
| 金额／收益率 | 金额要结合本金和时间，收益率也要口径 | 赚1000元，是投1万还是100万？ |
| 百分比／百分点 | 比例与两个比率的差 | 2%到3%是相对涨50%还是1个百分点？ |
| 收入／利润／现金 | 经营规模、会计成果、实际收付 | 借来100万会让利润多100万吗？ |
| 资产／权益 | 资产扣负债才是权益 | 有资产100、欠80，股东剩多少？ |
| 账面权益／市值 | 会计记录与市场定价 | 股价跌会使公司现金同步减少吗？ |
| 股息／利息 | 普通股分配与债务合同支付 | 不派普通股息一定违约吗？ |
| 股权／债权 | 剩余权益与合同请求权 | 清算后没有剩余，普通股能优先取回吗？ |
| 一级／二级市场 | 新发行与既有证券转让 | 这笔买入款进入谁的账户？ |
| IPO／上市 | 公开发售与获准市场买卖 | 介绍上市会同时募集新钱吗？ |
| 新股／旧股出售 | 公司融资与出售股东变现 | IPO的全部所得都归公司吗？ |
| 红股／供股 | 通常不另缴款与须认购付款 | 股数都变多，为什么现金不同？ |
| 拆股／价值增长 | 单位变化与经济价值创造 | 一拆二后总财富会自动翻倍吗？ |
| 除净／记录／付款日 | 交易附权、资格登记、实际支付 | 记录日当天买入必定附权吗？ |
| 股息率／派息比率 | 股息除价格与股息除盈利 | 股价跌为何股息率会上升？ |
| 票息率／当前收益率／YTM | 面值、买价、完整现金流折现 | 低价买债后票息率会自动改吗？ |
| 贴现率／投入收益率 | 面值与投入价格作分母 | 99买100收，利润除99还是100？ |
| 净价／全价 | 是否加应计利息 | 报价990，付款会只付990吗？ |
| 期限／久期 | 合同到期时间与现金流加权时间等 | 两年付息债久期必等于两年吗？ |
| 名义／实际收益 | 是否调整通胀 | 扣佣金后就叫实际购买力回报吗？ |
| 基金净值／交易价 | 资产净额与市场买卖报价 | ETF溢价消失会不会影响买方？ |
| 普通ETF／每日杠反产品 | 策略、目标和重设不同 | 指数两日回原点，两倍产品呢？ |
| REIT／普通地产公司 | 结构与约束不同 | 高分派是否代表无债务风险？ |
| 股票／期权／权证 | 股东权利与合约权利 | 持认购权证能直接投票吗？ |
| 期权收益／净损益 | 是否扣权利金与费用 | 价内3、成本6，真的赚了吗？ |
| 买Put／卖Call | 下跌方向可能相似，但义务不同 | 最大收益和损失有何区别？ |
| 远期／期货 | 定制场外与常见标准化交易结算 | 能否把每种远期都当每日结算？ |
| 期货保证金／货款 | 履约担保与购买对价 | 初始保证金是不是最大亏损？ |
| 名义本金／实际交换现金 | 计算基准与本期流量 | 同币种掉期是否每期交换全部本金？ |
| 借券／卖空 | 借贷安排与卖出行为 | 借来做交收就必定投机吗？ |
| 对冲／投机 | 看原始敞口和目的 | 面包厂买小麦期货的整体风险怎样变？ |
| 备兑／保本 | 能交付股票不代表不亏 | 股票跌50%，权利金能完全抵消吗？ |
| 公司权证／第三方衍生权证 | 发行人、交付和摊薄不同 | 哪种可能导致标的公司发新股？ |
| R类／N类牛熊证 | 收回价和行使价及剩余价值安排 | R类剩余值能否为零？ |
| 经纪／交易所／监管者 | 执行服务、市场规则、监督执法 | 谁替个人下单，谁查行为？ |
| 托管／登记 | 保管支持与法律名册服务 | 经纪账户持仓是否必定本人登记？ |
| 参与资格／牌照／考试 | 交易所资格、法定业务许可、胜任要求 | Paper8等于第8类牌照吗？ |
| 成交／交收 | 买卖条款成立与实际履行 | 手机成交后钱是否都可立即提走？ |
| T+2／两日 | 适用营业日与自然日 | 星期五后第二天是星期日还是星期二？ |
| CCP保护／市场风险 | 履约风险管理与价格波动 | 中央结算能否让股价不跌？ |
| HKIDR／OTCR | 身份联系与场外汇报 | 一个编码能替代所有事件报告吗？ |
| 电子下单／USM | 交易处理与法律持有形式 | 无纸交易界面等于无纸本人登记吗？ |
| 内控／内审／外审 | 日常控制、独立评价、财报审计 | 谁负责整改问题，谁复核有效性？ |
| ROE／经营质量 | 高回报也可能来自高杠杆 | 少量权益支撑大资产会怎样影响比率？ |
| 低P/E／便宜 | 价格相对盈利低，不等于低风险 | 盈利在周期顶峰时低倍数可靠吗？ |
| D0／D1 | 刚过去股息与下一期股息 | 戈登分子该用哪个时点？ |
| 超买／即将下跌 | 历史相对强弱与未来判断 | 强趋势可否一直在高RSI？ |
| 回测成功／未来保证 | 样本内表现与未来实现不同 | 费用、退市公司和未来数据算进了吗？ |

## 复习方法

遮住第二列，先回答第三列，再写两种概念各一句定义。如果答案只能背名词，回到讲义画资金流或时间轴。对同一误区连续两次答错，就把自己的错误推理原样写入错题本，隔几天再用新的金额重做。
