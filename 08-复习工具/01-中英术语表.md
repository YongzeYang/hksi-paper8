# 01 中英术语表：随时查，不要求一次背完

[首页](../README.md) · [易混概念](03-易混概念对照.md)

先读讲义中的故事，再回来查正式名称。释义是入门解释；法律定义、产品条款和具体考试范围以适用官方文件为准。

## 金融基础

| 中文 | English / 缩写 | 人话解释 |
|---|---|---|
| 融资 | Financing | 资金需求方向外部或内部取得资金的安排。 |
| 投资 | Investment | 投入资源换取预期未来收益，同时承担不确定性。 |
| 证券 | Security | 体现特定财产或合同权利的工具，具体法律范围按制度。 |
| 资产 | Asset | 企业控制并预期带来经济利益的资源。 |
| 负债 | Liability | 企业需履行的现时义务。 |
| 权益 | Equity | 资产扣负债后的剩余权益。 |
| 股权 | Ownership Interest | 公司所有者的剩余权益及相关权利。 |
| 债权 | Creditor Claim | 依合同等取得收款或其他履约的请求权。 |
| 本金 | Principal | 计算投资、借款或偿还的基础金额。 |
| 利息 | Interest | 资金使用和时间等因素对应的合同支付。 |
| 股息／股利 | Dividend | 公司按适用安排向股东作出的分配。 |
| 收入 | Revenue | 经营活动形成的收入，不等于收到现金。 |
| 利润 | Profit | 指定期间收入扣相关费用等后的成果。 |
| 现金流 | Cash Flow | 期间现金流入与流出。 |
| 留存收益 | Retained Earnings | 累计利润扣分配等后的会计权益余额，不是专属现金袋。 |
| 市值 | Market Capitalisation | 相关股价乘股份数量。 |
| 账面价值 | Book Value | 按会计口径记录的资产、权益等金额。 |
| 价格／价值 | Price / Value | 交易对价与分析估计的经济价值，可能不同。 |

## 数学与市场

| 中文 | English / 缩写 | 人话解释 |
|---|---|---|
| 百分比 | Percentage | 以一百为单位的比例，5%=0.05。 |
| 百分点 | Percentage Point | 两个百分率水平之差。 |
| 基点 | Basis Point, bp | 0.01个百分点，100基点=1个百分点。 |
| 持有期收益 | Holding Period Return | 指定持有期间的收入与价格净变化相对投入。 |
| 年化收益 | Annualised Return | 将不同期间回报转换为年度比较口径。 |
| 复利 | Compounding | 利息或收益留在本金中继续参与以后收益。 |
| 现值 | Present Value, PV | 未来现金按要求收益率折回指定当前时点的价值。 |
| 终值 | Future Value, FV | 当前金额按计息条件增长至未来的金额。 |
| 折现率 | Discount Rate | 用于现金流时间及风险比较的回报要求。 |
| 加权平均 | Weighted Average | 各项目按其权重贡献汇总，先说明权重口径。 |
| 实际收益 | Real Return | 调整通胀后的购买力回报。 |
| 货币市场 | Money Market | 主要服务短期资金及工具的市场。 |
| 资本市场 | Capital Market | 主要服务较长期资金和权益融资的市场。 |
| 一级市场 | Primary Market | 发行证券的市场阶段。 |
| 二级市场 | Secondary Market | 已发行证券持有人之间转让的市场。 |
| 场外 | Over-the-Counter, OTC | 不通过所指交易所集中市场的交易安排。 |
| 现货 | Spot / Cash Market | 直接买卖有关资产，仍可有交收周期。 |
| 标的 | Underlying | 衍生工具所挂钩的资产、指数或其他变量。 |
| 流动性 | Liquidity | 以合理成本及时进行所需规模交易或取得现金的能力。 |
| 价差 | Bid–Ask Spread | 最佳卖价与最佳买价之差。 |
| 深度 | Market Depth | 不同价格水平可交易数量。 |
| 波动率 | Volatility | 收益或价格变化程度的统计量，不概括所有风险。 |
| 系统性风险 | Systematic Risk | 市场共同因素导致、难单靠分散个股消除的风险。 |
| 非系统性风险 | Unsystematic Risk | 个别企业等特有风险，可由适当分散降低。 |
| 通胀 | Inflation | 一般价格水平上升，削弱货币购买力。 |
| 汇率 | Exchange Rate | 一种货币以另一种货币表示的价格。 |
| 指数 | Index | 按样本、权重及调整规则形成的市场度量。 |
| 自由流通量 | Free Float | 按具体方法认定可在市场流通的部分。 |
| 总回报 | Total Return | 同时考虑价格及分配等的回报口径。 |

## 发行、公司行动与角色

| 中文 | English / 缩写 | 人话解释 |
|---|---|---|
| 首次公开招股 | Initial Public Offering, IPO | 首次公开发售证券，可能含新股和旧股。 |
| 上市 | Listing | 证券获准在相关市场买卖的安排。 |
| 招股章程 | Prospectus | 载明业务、风险、财务与发行等资料的文件。 |
| 配售 | Placing | 向选定投资者分配证券的安排。 |
| 介绍上市 | Listing by Introduction | 通常不同时公开募集新资金的上市方法。 |
| 供股 | Rights Issue | 按条件给予现有合资格股东缴款认购新股的机会。 |
| 红股 | Bonus Share | 按安排向股东分配额外股份，通常不另缴认购款。 |
| 拆股 | Share Split | 把每一旧股分成更多单位，理论总值不因此改变。 |
| 合股 | Share Consolidation | 合并股份单位，股数减少、理论单价提高。 |
| 除净 | Ex-entitlement | 交易不再附带指定公司行动权利。 |
| 记录日 | Record Date | 依安排确定登记资格的日期。 |
| 摊薄 | Dilution | 持股比例或某些每股指标因资本变化而减少。 |
| 回购 | Share Repurchase | 公司按安排买回股份。 |
| 经纪 | Broker | 提供相关客户交易执行等服务的中介。 |
| 代理 | Agent | 代表客户等委托方办事的身份。 |
| 主事人 | Principal | 以自身名义或账户成为交易一方的身份。 |
| 分析员 | Research Analyst | 研究证券与企业并提出有假设的分析判断。 |
| 保荐人 | Sponsor | 承担相关上市申请及尽职调查职能的专业中介。 |
| 承销商 | Underwriter | 依承销安排承担责任并协助分销的机构。 |
| 托管人 | Custodian | 提供资产保管、交收支持及相关服务。 |
| 证券登记机构 | Securities Registrar | 维护名册、过户及公司行动等服务。 |
| 家族办公室 | Family Office | 服务家族投资及相关事务的安排，牌照视实际活动。 |
| 套利 | Arbitrage | 利用相关价格差的组合交易思路，执行仍可能有风险。 |
| 对冲 | Hedging | 降低已有风险敞口的交易或安排。 |
| 投机 | Speculation | 主动承担风险以寻求价格等收益。 |

## 产品

| 中文 | English / 缩写 | 人话解释 |
|---|---|---|
| 普通股 | Ordinary Share | 通常承担剩余风险、享有适用股东权利的股份。 |
| 优先股 | Preference Share | 在指定分配等方面具有条款所定优先性的股份。 |
| 累积优先股 | Cumulative Preference Share | 未付优先股息按条款累积。 |
| 合订证券 | Stapled Securities | 多项证券权益按安排组合交易。 |
| 单位信托 | Unit Trust | 以信托等相关法律安排汇集资金投资。 |
| 互惠基金 | Mutual Fund | 常见公司结构的集合投资工具，依司法区而异。 |
| 资产净值 | Net Asset Value, NAV | 资产价值减负债，单位净值还需除单位数。 |
| 交易所买卖基金 | Exchange Traded Fund, ETF | 在交易所买卖、并有特定申赎安排的基金。 |
| 溢价／折价 | Premium / Discount | 市场价相对参考净值等高出／低于的程度。 |
| 跟踪误差 | Tracking Error | 基金与基准回报差的波动指标，定义看披露。 |
| 杠杆及反向产品 | Leveraged and Inverse Products | 依文件追求每日倍数或反向目标等的产品。 |
| 房地产投资信托 | Real Estate Investment Trust, REIT | 通过受规管结构参与房地产组合收益。 |
| 存托凭证 | Depositary Receipt, DR | 按存托结构代表底层证券权益的凭证。 |
| 同业拆借 | Interbank Lending | 银行等机构间资金借贷。 |
| 银行承兑汇票 | Banker’s Acceptance | 由银行承兑承担相关付款责任的票据。 |
| 商业票据 | Commercial Paper, CP | 企业短期融资的常见债务工具。 |
| 存款证 | Certificate of Deposit, CD | 按条款发行的可转让存款类凭证。 |
| 政府短票 | Government Bill | 政府发行的短期债务工具。 |
| 回购协议 | Repurchase Agreement, Repo | 卖出并约定买回证券、经济上常用于抵押融资。 |
| 折扣 | Haircut | 抵押品市值与可计融资价值之间的缓冲。 |
| 面值 | Face / Par Value | 债务合同计算本金等的基准，不是市场保证价。 |
| 票息率 | Coupon Rate | 票息相对面值的比率。 |
| 当前收益率 | Current Yield | 年票息除当前价格。 |
| 到期收益率 | Yield to Maturity, YTM | 令承诺现金流现值等于价格的收益率。 |
| 应计利息 | Accrued Interest | 上次付息后按约定累积但尚未支付的利息。 |
| 净价／全价 | Clean / Dirty Price | 不含／含应计利息的常见报价口径。 |
| 久期 | Duration | 现金流时间和利率敏感度的相关指标，须分种类。 |
| 凸性 | Convexity | 价格与收益率关系弯曲的敏感度。 |
| 信用利差 | Credit Spread | 相对有关基准的收益补偿，需统一期限币种。 |
| 融资／孖展 | Margin Financing | 以借款等支持证券持仓的融资安排。 |
| 追加保证金 | Margin Call | 按约定补充资金或抵押品的要求。 |
| 证券借贷 | Stock Borrowing and Lending | 借入并归还等量等类证券等的合同安排。 |
| 卖空 | Short Selling | 卖出借入或以适用担保安排取得交付权的证券。 |
| 远期 | Forward | 约定未来交换的通常定制合同。 |
| 期货 | Futures | 常见交易所标准化、集中结算的未来交易合约。 |
| 掉期 | Swap | 按条款交换一串现金流等的合约。 |
| 名义本金 | Notional Principal | 计算合约现金流或敞口的基准金额。 |
| 基差 | Basis | 现货与期货价格之差，定义方向先看题设。 |

## 期权与基础设施

| 中文 | English / 缩写 | 人话解释 |
|---|---|---|
| 认购／认沽 | Call / Put | 按条款买入／卖出标的的权利。 |
| 权利金 | Premium | 取得期权等权利支付的价格。 |
| 行使价 | Strike Price | 按期权条款买卖标的的约定价格。 |
| 欧式／美式 | European / American Style | 按条款允许行使时点的两种风格。 |
| 内在价值 | Intrinsic Value | 普通教学情境下立即行使的有利价差。 |
| 时间价值 | Time Value | 价格中相对于内在价值的部分，严格边界依模型。 |
| 隐含波动率 | Implied Volatility, IV | 由市价及模型反推的波动输入。 |
| Delta | Delta | 期权对标的价格小幅变化的敏感度。 |
| Gamma | Gamma | Delta对标的价格变化的敏感度。 |
| Theta | Theta | 时间流逝的价格敏感度，单位先核对。 |
| Vega | Vega | 波动率变化敏感度，常按波动率百分点报价。 |
| Rho | Rho | 利率变化敏感度，需确认单位。 |
| 保护性认沽 | Protective Put | 持股加买认沽的下跌保护策略。 |
| 备兑认购 | Covered Call | 持股加卖认购，收权利金但限制上涨。 |
| 跨式 | Straddle | 同到期同行使价认购与认沽组合。 |
| 衍生权证 | Derivative Warrant | 第三方发行并挂钩标的的权证。 |
| 牛熊证 | Callable Bull/Bear Contract, CBBC | 含强制收回安排的结构性产品。 |
| 强制收回 | Mandatory Call Event, MCE | 触发指定条件导致产品提前终止的事件。 |
| 代币化证券 | Tokenised Securities | 以相关技术表示传统证券权利的安排。 |
| 香港交易所 | HKEX | 集团层面名称，旗下交易与结算机构各有分工。 |
| 香港联交所 | SEHK | 相关证券上市与交易市场机构。 |
| 香港期交所 | HKFE | 相关期货及期权交易市场机构。 |
| 香港中央结算 | HKSCC | 相关现金证券清算交收基础设施机构。 |
| 联交所期权结算所 | SEOCH | 其适用股票期权的结算机构。 |
| 期货结算公司 | HKCC | 其适用期货期权的结算机构。 |
| 场外结算公司 | OTC Clear | 适用场外衍生品集中结算机构。 |
| 证监会 | SFC | 证券期货相关发牌、监督、监察与执法机构。 |
| 金管局 | HKMA | 货币银行等领域的相关机构。 |
| 中央对手方 | Central Counterparty, CCP | 按合约安排介入交易并集中管理履约风险。 |
| 合约更替 | Novation | 以新合同义务取代原双边关系等法律机制。 |
| 中央结算交收系统 | CCASS | 证券结算交收系统名称，非个人经纪。 |
| 持续净额交收 | Continuous Net Settlement, CNS | 适用证券及现金义务净额处理安排。 |
| 货银对付 | Delivery Versus Payment, DVP | 使证券与款项交付建立联系的安排。 |
| 投资者识别码制度 | HKIDR | 把相关订单交易联系到投资者身份信息。 |
| 客户编码 | Broker-to-Client Assigned Number, BCAN | 中介按制度分配并映射客户身份的编码。 |
| 客户识别信息 | Client Identification Data, CID | 按制度提交的客户身份相关资料。 |
| 场外证券交易汇报 | OTCR | 适用场外证券事件的汇报制度。 |
| 无纸证券市场 | Uncertificated Securities Market, USM | 本人名义电子持有及转让等制度安排。 |

## 分析与控制

| 中文 | English / 缩写 | 人话解释 |
|---|---|---|
| 基本分析 | Fundamental Analysis | 从经济、企业、报表和价值研究证券。 |
| 技术分析 | Technical Analysis | 研究价格成交数据的趋势与模式。 |
| 营业利润 | EBIT | 本文为扣利息税前的营业利润口径。 |
| 每股盈利 | Earnings Per Share, EPS | 归普通股盈利除适当加权股数。 |
| 每股股息 | Dividend Per Share, DPS | 每普通股的指定期间分派。 |
| 市盈率 | Price/Earnings, P/E | 价格除匹配的每股盈利。 |
| 市账率 | Price/Book, P/B | 价格除每股账面权益。 |
| 股息率 | Dividend Yield | 每股股息相对股价。 |
| 派息比率 | Payout Ratio | 分派相对盈利。 |
| 权益回报率 | Return on Equity, ROE | 相关利润相对权益，本文通常用平均权益。 |
| 资产回报率 | Return on Assets, ROA | 相关利润相对总资产，分子定义需说明。 |
| 流动比率 | Current Ratio | 流动资产除流动负债。 |
| 速动比率 | Quick Ratio | 按定义调整后的速动资产除流动负债。 |
| 利息保障倍数 | Interest Coverage | 相关营业利润相对利息费用。 |
| 企业价值 | Enterprise Value, EV | 股权价值加净债务等适当调整的价值口径。 |
| 股息折现模型 | Dividend Discount Model, DDM | 未来股息按要求收益率折现的模型。 |
| 简单移动平均 | Simple Moving Average, SMA | 固定窗口价格的算术平均。 |
| 指数移动平均 | Exponential Moving Average, EMA | 对近期数据权重较高的平滑序列。 |
| 相对强弱指标 | Relative Strength Index, RSI | 按指定平均涨跌幅构造的动量指标。 |
| 利益冲突 | Conflict of Interest | 不同责任与经济利益可能影响公平行为的情境。 |
| 适当性 | Suitability | 适用情境下使建议或产品与客户情况匹配的要求。 |
| 内部控制 | Internal Control | 权限、流程、记录和复核等控制安排。 |
| 内部审计 | Internal Audit | 独立评估控制设计与运行的职能。 |
| 压力测试 | Stress Testing | 评估极端或不利假设对资金和风险的影响。 |
| 业务持续计划 | Business Continuity Plan, BCP | 中断情况下维持或恢复关键业务的安排。 |
