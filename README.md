# HKSI Paper 8｜从零开始学证券

一套面向没有金融背景读者的原创中文学习资料：从“公司为什么需要钱”开始，逐步走到债券定价、期权、交易交收、财务分析和估值。简体中文为主，配英文及香港常用术语。

**按编号阅读，按理解调整进度。** 这里有4篇预备课、24篇主题讲义、84天学习任务、200道原创选择题及逐项解析，另有84道随文自测。每天约45–60分钟，默认12周。

## 今天就开始

1. 打开[第一天指导](00-学习导航/01-从今天开始.md)，照着第一小时任务做。
2. 阅读[01 企业为什么需要金融](01-零基础预备课/01-企业为什么需要金融.md)，画新股认购与旧股转让的资金箭头。
3. 完成该篇3道自测，再看折叠解析，用自己的话解释原因。
4. 到[84天任务表](00-学习导航/02-十二周每日任务.md)记录进度，不懂就把任务顺延。

不需要先背所有术语或公式。读不懂一个词时查[中英术语表](08-复习工具/01-中英术语表.md)；卡在计算时回到[数学预备课](01-零基础预备课/03-百分比收益率与加权平均.md)。

## 怎么才算理解

能把概念讲给同样没有背景的人；能写清变量和单位完成计算；换一个金额或条件仍能判断；知道结论的适用范围。每篇自测与掌握清单都围绕这些任务设计。

主线是虚构“海港面包公司”：融资、上市、交易、公司行动、读报表及估值。不同情景均标编号，数字前后一致。复杂产品另配独立情境。所有练习均为原创学习题，非官方试题。

## 维护与检查

无需安装依赖；Markdown可直接在GitHub或本地编辑器阅读。Mermaid流程图同时配文字说明，不支持图形也能学习。

```bash

```

脚本检查内部文件链接、题目与解析配对、四个选项、讲义自测、目录编号和一组关键计算；它不替代金融规则审阅。实际检查范围见[校验记录](10-资料依据与维护/04-校验记录.md)。
